#### 📊 [NetworkMonitor](https://github.com/3issam-hub/NetworkMonitor) · Shell
A real-time network traffic monitor written in Bash. It reads interface statistics from `/sys/class/net`, graphs RX/TX traffic with **Gnuplot**, and publishes an auto-refreshing HTML dashboard.
- Configurable interval, duration and output directory
- CSV export and a Zenity GUI for easy setup
- Packet, error and dropped-packet statistics

#### 🔍 [Wp-Explorer](https://github.com/3issam-hub/Wp-Explorer) · Python
A command-line tool that explores WordPress sites for sensitive paths and endpoints and reports the response status codes.
- WordPress detection and version identification
- User enumeration, plugin and theme detection
- Vulnerability checks through the WPScan database
- XML-RPC status check, multi-site scanning, export to text, JSON or CSV

> Built for authorized security testing and education only.
